# Plan: Issue #15 — Industry Configuration

## Context

Industries are the domain that determines which Surveys a Tenant operates with. This slice adds two new DB tables — `industries` (system-level, shared across all tenants) and `tenant_industries` (join table, tenant-scoped with RLS) — along with the API endpoints and a UI page for Tenant Admins to enable/disable Industries for their tenant.

Blocking issue #06 (Tenant Admin login) is already done; auth/session/permission infrastructure is in place.

## API shape

**`GET /api/industries`** — requires `manage:industries`  
Response:
```json
{
  "industries": [
    { "id": "...", "name": "Blood Bank", "enabled": true },
    { "id": "...", "name": "Ambulatory Health Center", "enabled": false }
  ]
}
```

**`POST /api/tenant-industries`** — requires `manage:industries`  
Body: `{ "industryId": "uuid" }`  
Response: `{ "ok": true }` (201)

**`DELETE /api/tenant-industries/[id]`** — requires `manage:industries`; `[id]` is the industryId  
Response: `{ "ok": true }` (200) or `{ "error": "not_found" }` (404)
